Define the observation before fitting

  • Club × season × competition is one observation
  • Index = (recorded goals + assists) / source matches
  • Target = next consecutive season index − current index
  • Exclude inadequate season pairs and competition-unsafe lags.

07 / Findings · 09:15–10:15 · lilllaz

What the data supports

  • Transfer spend → next attacking change: r = −0.0036; n = 38,531
  • Defender spend → next conceded-goal change: r = +0.0040; p = 0.427
  • Same-season index ↔ position: r = −0.793; n = 388
  • Different targets; these are associations, not interventions.
  • Same temporal split: R² 0.127 → 0.150 with conceded rate, discipline and net spend
  • Red-card difference +0.341 conceded goals; observational, not causal
Заметки выступающего / RU

The augmented model adds features as a group; do not claim the improvement comes from one defensive variable. The red-card test is a same-match association, confounded by match state and opponent.
